# 中文资源导航网站 - 实施计划

## 项目目标
创建一个面向中文用户的合法资源导航网站，聚合各类免费、开放、合法的资源。

## 技术选型
- **生成器**: Hugo v0.119.0
- **样式框架**: Bootstrap 5
- **部署**: Vercel (推荐) / GitHub Pages
- **数据格式**: JSON

## 快速开始

### 环境准备
```bash
# 安装 Hugo
brew install hugo

# 验证安装
hugo version

# 创建项目
hugo new site navigation-website
cd navigation-website
```

### 基础部署
```bash
# 添加主题
git init
git submodule add https://github.com/thegeeklab/hugo-ana... theme/ananke

# 添加菜单配置
echo '[menu.main]' >> config.toml
echo '  [[menu.main]]' >> config.toml
echo '    name = "首页"' >> config.toml
echo '    url = "/"' >> config.toml
echo '    weight = 1' >> config.toml

# 启动开发服务器
hugo server -D
```

### 上线部署 (Vercel)
```bash
# 安装 Vercel CLI
npm install -g vercel

# 登录
vercel login

# 部署
vercel

# 自定义域名（可选）
vercel domain add yourdomain.com
```

## 数据录入指南

### 数据格式标准
每个资源应包含以下字段：
- `name` (必填): 网站名称
- `url` (必填): 完整 URL
- `description` (必填): 详细描述
- `category` (必填): er/sm/tools/entertainment
- `tags` (可选): 标签数组
- `rating` (可选): 评分 1-5，默认 5
- `language` (可选): 中文/英文，默认 中文

### 示例数据
```json
[
  {
    "name": "中国大学MOOC",
    "url": "https://www.icourse163.org",
    "description": "中国高校在线课程平台，提供国内外名校课程",
    "category": "education",
    "tags": ["在线课程", "免费", "大学"],
    "rating": 5,
    "language": "中文"
  }
]
```
