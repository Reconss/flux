## 💬 知识指南

### 什么是电视节目指南？
电视节目指南是显示当前和未来电视节目表单的网络服务。它们帮助用户决定观看哪些节目。

### 如何使用 TV Guide？
1. 访问 TV Guide 网站
2. 选择你的地区和时间
3. 浏览节目列表
4. 记录你想看的节目

### 常见分类
- 按时间: 每日/每周
- 按节目: 新闻/电视剧/电影
- 按平台: 阿里云/腾讯云
